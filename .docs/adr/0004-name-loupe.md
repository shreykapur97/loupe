# 0004 — Name: Loupe

Date: 2026-10-27 · Status: accepted · Decided by: shrey

## Context

The plugin needed a name that's free where Grasshopper users find plugins.
"Loupe", after the jeweller's magnifier, was checked on food4Rhino, GitHub
and the Rhino Package Manager, where package names must be unique
(`case-study.md` → Findings, 2026-10-27).

## Decision

- The plugin, assembly, repo and package are all called Loupe.

## Consequences

- The Package Manager name should be claimed with a first release before
  someone else takes it (`phases.md` → Phase 4).
