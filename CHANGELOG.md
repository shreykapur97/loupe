# Changelog

Downloads: [Releases](https://github.com/shreykapur97/loupe/releases).

## 0.4.0-alpha — 2026-10-27

- Lock and float / dock merged into one **pin** button: pinned, Loupe is
  fixed on the canvas; unpinned, it floats and can be moved and resized.
  Pinning it over the canvas drops it there.
- Four buttons instead of five.

## 0.3.0-alpha — 2026-10-27

- Five buttons down the left edge: lock, home, float / dock, view only,
  match view.
- Float Loupe in its own window anywhere on screen, and dock it back.
- View only, on by default: no editing, no pan or zoom.
- Opens at the main canvas's view; match view jumps back to it.
- Frame like Grasshopper's panel component; Lucide icons.
- Hides when the Grasshopper editor closes.

## 0.2.0-alpha — 2026-10-27

- Loupe is a framed panel on the canvas instead of a separate window.
- Lock and home buttons; no compass or zoom bar inside Loupe.
- New icon: a grasshopper under a magnifier.

## 0.1.1-alpha — 2026-10-27

- Fix: the toolbar button didn't appear.

## 0.1.0-alpha — 2026-10-27

- First build: a toolbar button that opens a second canvas on the same
  document.
